# Tanya's Auto Harvest

A small Fabric mod for Minecraft 26.2.

Right-click a fully grown crop to collect its normal drops and immediately reset the crop to age 0. Replanting is free and does not remove an item from the player's inventory.

Supported crops:

- Wheat
- Carrots
- Potatoes
- Beetroot

## Multiplayer

Install the mod on the server. For singleplayer, installing it in the client instance is enough because Minecraft runs an integrated server.

## Building

Use JDK 25, then run:

```text
./gradlew build
```

The finished mod jar is written to `build/libs/`.
