# Tanya's Auto Harvest

> Harvest and replant mature crops with a single right-click.

**Tanya's Auto Harvest** is a lightweight quality-of-life farming mod for
Fabric. It makes harvesting faster while keeping farming simple and
survival-friendly.

## Features

- Right-click a fully grown crop to harvest it instantly.
- The crop is automatically returned to its first growth stage.
- Normal crop drops are preserved.
- Farmland remains intact.
- Immature crops are ignored.
- No commands, keybinds, or configuration required.

## Supported crops

- Wheat
- Carrots
- Potatoes
- Beetroot

More crops may be supported in future updates.

## How to use

1. Wait for a supported crop to become fully grown.
2. Right-click the crop.
3. Collect the drops while the replanted crop begins growing again.

That is all—no seeds need to be selected and no special tool is required.

## Requirements

- **Minecraft:** 26.2
- **Mod loader:** Fabric Loader 0.19.3 or newer
- **Dependency:** Fabric API 0.156.0+26.2
- **Java:** 25 or newer

## Installation

1. Install Fabric Loader for Minecraft 26.2.
2. Install Fabric API.
3. Place Tanya's Auto Harvest in your `mods` folder.
4. Launch the game and start harvesting.

## Multiplayer

The harvesting logic runs on the server:

- **Single-player:** Install the mod and Fabric API in your Minecraft instance.
- **Multiplayer:** Install the mod and Fabric API on the Fabric server. Players
  can use the feature without installing the mod separately on their clients.
